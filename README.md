# EME Resilient Application Platform (EMERAP)
## Суверенна, Децентралізована Гібридно-Радіофізична Екосистема прикладних модулів

> **Кодова назва демонстраційного прототипу:** Mine & Craft Avatar Hub

---

## 1. Концепція та Філософія Платформи

**EME Resilient Application Platform (EMERAP)** — це локально-орієнтована (Local-First), стійка до катастроф (Survival) та цензури платформа для децентралізованих додатків. 

Платформа спроектована для роботи в екстремальних інфраструктурних умовах: від стабільного швидкісного інтернету до **повного відключення глобальної мережі (офлайн-блекаут)**. Вона об'єднує стандартні веб-технології із низькошвидкісними автономними Mesh-мережами (LoRa) та далеким іоносферно-космічним радіозв'язком (Середні хвилі Skywave, Земля-Місяць-Земля / Moon Bounce).

### Чому це НЕ просто ігрова платформа?
Поточний демонстраційний модуль (**Mine & Craft Avatar Hub + Match-3 Game**) — це виключно **Proof-of-Concept (демонстрація технології)**. Гра та аватар використовуються для наочної перевірки:
1.  **Суворої ізоляції сторонніх модулів (Secure Sandbox):** Доказ того, що сторонні розробники можуть безпечно запускати свої сервіси на платформі.
2.  **Мікро-транзакцій в офлайні:** Генерація та валідація ігрових ресурсів без центрального сервера.
3.  **Надкомпактного дельта-стиснення (MessagePack $\le 150$ байт):** Перевірка того, що стан системи може передаватися через надповільні радіолінки ($31\text{--}250 \text{ bps}$).

У реальній експлуатації ігрова Match-3 гра та аватар можуть бути миттєво замінені або доповнені набором **критично важливих громадських та комунікаційних утиліт**.

## 2. Глобальні сфери застосування Платформи (Поза іграми)

Завдяки вбудованому ядру синхронізації дельт та криптографічному захисту за допомогою особистих ключів, EMERAP є платформою для наступних сервісів:

*   **Стійкий Повільний Чат (Resilient Messenger):**
    Обмін текстовими повідомленнями. В межах району/міста — миттєво (через локальні Wi-Fi хотспоти та LoRa Mesh). Між містами та континентами — у вигляді черги радіоповідомлень через середньохвильовий ефір або відскок від Місяця.
*   **Громадські Канбан-Дошки (Community task tracking):**
    Координація відновлювальних робіт, розподіл обов'язків при будівництві громадських об'єктів (наприклад, сонячних електростанцій, систем водоочищення). Зміна статусу завдання займає всього 40 байт і миттєво реплікується по Mesh-мережі.
*   **Децентралізовані дошки оголошень (Bulletin Boards):**
    Локальний ринок товарів та послуг (бартер, оренда інструментів, пошук спеціалістів, координація допомоги) без цензури та потреби в інтернеті.
*   **Суверенна офлайн-бухгалтерія та взаємозаліки (Mesh Ledger):**
    Вбудований утилітарний блокчейн (з консенсусом Proof of Coverage) дозволяє вести взаєморозрахунки у токенах EME, фіксувати передачу ресурсів та заохочувати операторів радіовузлів і сонячних станцій живлення.
*   **Розподілена База Знань (Survival Wiki):**
    Локальне реплікування медичних інструкцій, креслень, карт та посібників з автономного виживання (режим бази знань `kb.sqlite3`).

## 3. Гібридна Архітектура Системи

Система автоматично адаптується під поточний стан зв'язку, використовуючи один із 4 режимів:

```
[ Користувач / PWA UI ] 
        │
        ├──► 1. Local Mode (100% Offline) ──► Збереження в IndexedDB браузера
        │
        ├──► 2. Cloud Mode (З інтернетом)  ──► Прямі REST-запити до GitHub API (без серверів)
        │
        ├──► 3. Hybrid Mode (Локальний ПК) ──► companion.py ──► Локальний Git Commit & Push
        │
        └──► 4. EME Mesh Mode (Офлайн)     ──► EME OS вузол ──► MessagePack Delta ──► Радіоефір (LoRa/MW/EME)
```

### Opaque Sandbox (Шар безпеки додатків)
Будь-який прикладний модуль (будь то гра Match-3, чат чи канбан-дошка) запускається всередині `<iframe>` із суворим атрибутом `sandbox="allow-scripts"`.
Через відсутність прапорця `allow-same-origin` додаток отримує статус **opaque origin (ізольоване джерело)**. Він фізично позбавлений можливості зчитати ваші токени, паролі чи IndexedDB бази даних головного Хабу. Зв'язок відбувається через безпечний протокол `postMessage` за допомогою одноразових UUID-токенів сесії.

## 4. Інструкція з Деплою на GitHub Pages (Крок за кроком)

Цей репозиторій повністю готовий до безкоштовного хостингу на GitHub Pages. Завдяки нашому безсерверному хмарному клієнту (Cloud Mode), вам не потрібно запускати жодних серверів у себе на комп'ютері для повноцінної гри та збереження прогресу.

### Крок 1. Створення репозиторію на GitHub
1. Увійдіть у свій аккаунт на [github.com](https://github.com).
2. Створіть новий публічний (або приватний) репозиторій. Назвіть його, наприклад, `emerap-hub` або `mine-avatar-saves`.

### Крок 2. Завантаження коду в GitHub репозиторій
Відкрийте термінал (або Git Bash) у папці з проектом (`d:\dev\mine-avatar-hub`) та виконайте наступні команди:

```bash
# Ініціалізуємо локальний Git репозиторій
git init

# Додаємо всі файли проекту
git add .

# Створюємо перший комміт
git commit -m "Initial deploy of EME Resilient Platform and demo modules"

# Вказуємо гілку за замовчуванням
git branch -M main

# Зв'язуємо з вашим GitHub репозиторієм (замініть на ваше посилання)
git remote add origin https://github.com/ВАШ_НІК/emerap-hub.git

# Пушимо код
git push -u origin main
```

### Крок 3. Активація GitHub Pages
1. Перейдіть на сторінку вашого репозиторію на GitHub.
2. Відкрийте вкладку **Settings** (Налаштування) у верхньому меню.
3. У лівому сайдбарі знайдіть розділ **Pages** (сторінки).
4. У блоці **Build and deployment** у випадаючому списку **Source** оберіть **Deploy from a branch**.
5. У полі **Branch** виберіть гілку `main` та папку `/ (root)`.
6. Натисніть кнопку **Save** (Зберегти).

> Зачекайте 1–2 хвилини. GitHub згенерує для вас унікальне публічне посилання (наприклад: `https://yourname.github.io/emerap-hub/`).

## 5. Запуск та Експлуатація Системи

Тепер ви можете користуватися системою у будь-якому з режимів:

### А. Гра через Інтернет з автозбереженням на GitHub (Cloud Mode)
1. Відкрийте ваше згенероване посилання `https://yourname.github.io/emerap-hub/` на комп'ютері або смартфоні.
2. Натисніть кнопку **«⚙️ Налаштувати GitHub Cloud»** у лівій панелі.
3. Заповніть поля:
   * **GitHub Token (PAT):** Ваш токен (згенеруйте його в Settings -> Developer Settings -> Personal Access Tokens -> Tokens (classic) на GitHub з правами `repo`).
   * **Репозиторій:** Назва вашого репозиторію (`yourname/emerap-hub`).
   * **Шлях:** Шлях до файлу збереження (наприклад, `saves/save.json`).
4. Натисніть **«Зберегти та Синхронізувати»**.
5. **Готово!** Індикатор зверху стане синім. Тепер кожна дія, покупка чи зароблений у Match-3 ресурс будуть автоматично коммітитися прямо у ваш репозиторій на GitHub.

### Б. Офлайн-гра в дорозі (PWA Offline)
Оскільки платформа є Progressive Web App, після першого відкриття сайту з інтернетом ви можете вимкнути мережу, знову зайти за цією ж адресою, і гра відкриється повністю офлайн з кешу браузера. Всі збереження накопичуватимуться локально в IndexedDB і автоматично «запушаться» на GitHub, як тільки з'явиться зв'язок.

### В. Робота через десктопний Git-міст (Hybrid Desktop)
Якщо ви хочете мати локальну копію збережень на жорсткому диску з автоматичним версіонуванням:
1. Запустіть у терміналі локальний скрипт:
   ```bash
   python companion.py
   ```
2. Відкрийте локальний файл `index.html` або запустіть сайт. Платформа виявить Companion на порту 8989 і перейде в режим **«Hybrid Desktop Active»** (бірюзовий індикатор), автоматично зберігаючи файли через локальний Git CLI.
